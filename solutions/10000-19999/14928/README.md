# 14928 - 큰 수 (BIG)

| 시간 제한 | 메모리 제한 |
| --- | --- |
| 2 초 | 512 MB |

## 문제

<p>제연이는 그의 생일(2000년 3월 3일)을 기념해 자신이 가장 좋아하는 수를 20000303으로 나눈 나머지를 구해 그 수만큼 잠을 자기로 했다. 제연이가 얼마나 잠을 잘 수 있을지 구하자.</p>

## 입력

<p>첫째 줄에 제연이가 가장 좋아하는 수&nbsp;N이 주어진다. (N ≤ 10<sup>1,000,000</sup>)</p>

## 출력

<p>N을 20000303으로 나눈 나머지를 출력한다.</p>

## 태그

- 성공
- 수학
- 사칙연산
- 임의 정밀도 / 큰 수 연산
