## 문제

<p>연세대학교의 영문명은 YONSEI, 슬로건은 Leading the Way to the Future이다.</p>

<p>이를 출력하는 프로그램을 작성해보도록 하자.</p>

## 입력

<p>첫째 줄에 N이 주어진다. (N = 0 또는 1)</p>

## 출력

<ul>
	<li>N = 0일 경우: 연세대학교의 영문명을 출력한다.</li>
	<li>N = 1일 경우: 연세대학교의 슬로건을 출력한다.</li>
</ul>

<p>대소문자 구별에 주의하도록 하자.</p>
