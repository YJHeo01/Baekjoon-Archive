# 19525 - Rectangle-free Grid

| 시간 제한 | 메모리 제한 |
| --- | --- |
| 1 초 | 256 MB |

## 문제

<p>Construct an $N \times N$ grid with the following conditions:</p>

<ul>
	<li>$2 \leq N \leq 150$</li>
	<li>Each cell is filled with either '<code>O</code>' or '<code>.</code>'.</li>
	<li>There are at least 1700 cells with '<code>O</code>'.</li>
	<li>For each tuple of four integers $i, j, k, l$ such that $1 \leq i &lt; j \leq N$ and $1 \leq k &lt; l \leq N$, at least one of the four cells $(i,k)$, $(i,l)$, $(j,k)$, $(j,l)$ is filled with '<code>.</code>'.</li>
</ul>

## 입력

<p>There is no input.</p>

## 출력

<p>The first line should contain an integer $N$. The following $N$ lines should contain $N$ characters each ('<code>O</code>' or '<code>.</code>'), and these $N$ lines describe the grid.</p>

## 태그

- 실패
- 스페셜 저지
- 다국어
- 보기
- 수학
- 애드 혹
- 정수론
- 해 구성하기
