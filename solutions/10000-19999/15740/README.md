# 15740 - A+B - 9

| 시간 제한 | 메모리 제한 |
| --- | --- |
| 1 초 | 512 MB |

## 문제

<p>두 정수 <em>A</em>와 <em>B</em>를 입력받은 다음, <em>A</em>+<em>B</em>를 출력하는 프로그램을 작성하시오.</p>

## 입력

<p>첫째 줄에 <em>A</em>와 <em>B</em> (-10<sup>10000</sup> ≤ <em>A</em>, <em>B</em> ≤ 10<sup>10000</sup>)가 주어진다.</p>

## 출력

<p>첫째 줄에 <em>A</em>+<em>B</em>를 출력한다.</p>

## 태그

- 성공
- 서브태스크
- 수학
- 사칙연산
- 임의 정밀도 / 큰 수 연산
