# 1550 - 16진수

| 시간 제한 | 메모리 제한 |
| --- | --- |
| 2 초 | 128 MB |

## 문제

<p>16진수 수를 입력받아서 10진수로 출력하는 프로그램을 작성하시오.</p>

## 입력

<p>첫째 줄에 16진수 수가 주어진다. 이 수의 최대 길이는 6글자이다. 16진수 수는 0~9와 A~F로 이루어져 있고, A~F는 10~15를 뜻한다. 또, 이 수는 음이 아닌 정수이다.</p>

## 출력

<p>첫째 줄에 입력으로 주어진 16진수 수를 10진수로 변환해 출력한다.</p>

## 태그

- 성공
- 수학
- 구현
