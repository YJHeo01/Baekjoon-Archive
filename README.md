## 📌 소개

이 저장소는 백준 온라인 저지에 남아 있던 저의 제출 기록과 성장 과정들을 보존하기 위해 제작되었습니다.

백준 온라인 저지는 저에게 단순한 문제풀이 사이트가 아니라,

* 알고리즘 문제해결력을 키울 수 있는 공간이자
* 수많은 시행착오와 성장의 공간이었으며
* 여러 사람들과 경쟁하고 교류했던 무대였습니다.

서비스 종료 이후에도 기록을 보존하기 위해,
지금까지의 추억을 남길 수 있는 공간으로 이 저장소를 만들었습니다.

```text id="y0d9j2"
│       ├── problem.html

└── solutions/
    ├── index.json
    └── {range}/
        └── {problem_id}/
            ├── README.md
            ├── statement/
            │   ├── problem.json
            │   ├── problem.html
            │   └── problem.png
            └── submissions/
                ├── {submission_id}.json
                └── {submission_id}.{ext}
```

`{range}`는 `1000-9999`, `10000-19999`, `20000-29999`, `30000-`, `contest`로 분류됩니다.
